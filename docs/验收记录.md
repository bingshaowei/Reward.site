## 重现验证

在本机启动 `npm run dev:local -- --demo` 后，可以运行 `node --import tsx scripts/http-smoke.ts`。此脚本只允许本机开发地址，会创建名称明确的验收账号与示例任务。

容器验收首次配置与启动：

```sh
node scripts/prepare-container-check.mjs
docker compose --env-file .data/container-check.env -p bounty-check -f compose.yaml -f compose.test.yaml up -d --build
node scripts/container-check.mjs
```

随机配置文件已存在时无需重新生成；再次执行只需启动测试项目并运行检查脚本。恢复测试只作用于独立的 `bounty-restore-check` 项目卷，不操作开发或生产数据库。测试数据、备份均保留。
